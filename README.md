# NMMS VIII Standard Science – Interactive Quiz Repository

This repository contains the complete set of 17 Class VIII Science topic-wise interactive quizzes.

## How to use
1. Open `index.html` in a browser.
2. Select a chapter.
3. Students can complete the quiz and use the report-download feature included in the chapter quiz.

## Hosting on GitHub Pages
Upload the **contents of this folder** to the root of a GitHub repository. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. The published site will use `index.html` as its home page.

## Important
The question counts shown are the counts associated with the selected quiz files. This packaging step organizes the files; it is not a fresh independent verification of every question and answer key. Please report any suspected answer-key issue so the corresponding source question can be checked and corrected.


## Navigation update (20 November 2026)
All 17 chapter quizzes now show one question at a time, with Previous and Next navigation. Answer feedback stays visible until the learner chooses to continue. Students can revisit earlier questions; previously submitted answers remain locked to preserve the recorded score.
